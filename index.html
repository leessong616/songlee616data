마주 보는 두 각의 합은 직접 계산해 보세요.

∠A + ∠C와 ∠B + ∠D는 직접 계산해서 쓰고 ‘계산 확인’을 눌러 맞았는지 확인하세요.

2

규칙 찾기

기록표를 보고 빈칸을 채워 보세요.

D가 원의 내부 → ∠B + ∠D 180°
D가 원 위 → ∠B + ∠D 180°
D가 원의 외부 → ∠B + ∠D 180°
∠A + ∠C는 ∠B + ∠D와 더하면 항상 °이므로, 한 쌍만 확인해도 된다.

3

왜 그럴까?

D가 원 위에 있지 않을 때, 직선 AD가 원과 만나는 점을 E라고 합시다.
E는 원 위에 있으니 사각형 ABCE는 원에 내접하고, 지난 시간에 배운 대로 ∠B + ∠AEC = 180°입니다.
이제 ∠ADC가 ∠AEC보다 큰지 작은지만 비교하면 됩니다.

기억나나요? 삼각형의 외각의 크기는 그와 이웃하지 않은 두 내각의 크기의 합과 같습니다.
그래서 외각은 그 두 내각 하나하나보다 항상 큽니다.

D가 원의 내부에 있을 때

  1. AD를 D 쪽으로 길게 늘여서 원과 만나는 점을 E라 한다.
  2. 삼각형 DEC에서 ∠ADC는 외각이다.
    그래서 ∠ADC = ∠DEC + ∠DCE
  3. 두 각을 더한 것이니 ∠ADC는 ∠DEC보다 크다.
    즉 ∠ADC > ∠AEC
  4. 양쪽에 ∠B를 더하면 ∠B + ∠ADC > ∠B + ∠AEC = 180°

D가 원의 외부에 있을 때 (스스로 해 보기)

  1. 선분 AD가 원과 만나는 점을 E라 한다.
  2. 삼각형 EDC에서 ∠AEC는 외각이다.
    그래서 ∠AEC = ∠EDC + ∠ECD
  3. 두 각을 더한 것이니 ∠AEC는 ∠EDC(= ∠ADC)보다 크다.
    즉 ∠ADC < ∠AEC
  4. 양쪽에 ∠B를 더하면 ∠B + ∠ADC < ∠B + ∠AEC = 180°

그러므로 ∠B + ∠D = 180°가 되는 것은 D가 원 위에 있을 때뿐입니다.

오늘 찾은 성질

한 쌍의 대각의 크기의 합이 180°인 사각형은 원에 내접한다.

지난 시간: 원에 내접한다 → 대각의 합이 180°
오늘: 대각의 합이 180° → 원에 내접한다

두 방향이 모두 맞습니다.
그래서 원의 중심을 몰라도 각도만 재면 네 점이 한 원 위에 있는지 알 수 있습니다.

(1) D가 원 위에 서려면 ∠ADC = °

풀이 보기

현실과 연결

스톤헨지 복원 때 각도 말고 원 위에 있는지 확인할 방법은?

답 보기

원의 중심을 찾아서 거리를 재는 방법이 있다.
돌 두 개를 잇는 선분의 한가운데를 직각으로 지나는 선(수직이등분선)을 두 개 그리면, 두 선이 만나는 점이 원의 중심이다.
그 중심에서 네 번째 돌까지의 거리가 반지름과 같은지 재면 된다.
하지만 넓은 유적에서는 이런 선을 정확히 긋기 어려워서 각도로 확인하는 방법이 더 편리하다.

예시 답안

평행선 사이 같은 쪽 두 각이라서 ∠A + ∠B = 180°이다.
∠B 대신 ∠C를 넣으면 ∠A + ∠C = 180°이므로 항상 내접한다.

직사각형·정사각형: 네 각이 모두 90°라서 마주 보는 두 각의 합이 90° + 90° = 180°이다.
항상 내접한다.
